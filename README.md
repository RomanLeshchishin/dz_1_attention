Воспроизводимость эксперимента

Среда выполнения:

- Google Colab, бесплатный тариф.
- GPU: NVIDIA T4.
- Python 3.
- PyTorch.
- Matplotlib.

Фиксация случайности:
- Seed персонального варианта: 42.

Конфигурация обучения:

- Размер контекста - 64
- Размерность модели - 128
- Количество голов - 4
- Количество блоков - 2
- Dropout - 0.1
- Оптимизатор - AdamW
- Learning rate - 0.0003
- Размер батча - 32
- Количество шагов - 600

Инструкция по запуску:

1. Открыть Google Colab.
2. Загрузить исправленный ноутбук dz1-bughunt.ipynb.
3. Выбрать среду выполнения с GPU T4.
4. Выполнить все ячейки последовательно, начиная с первой.
5. Убедиться, что проверки пройдены.
6. Запустить обучение модели.
7. Получить график функции потерь и пример генерации текста.

Результат: при повторном запуске с указанными параметрами модель должна обучаться, демонстрировать снижение функции потерь и генерировать текст с характерными структурами обучающего корпуса. Возможны небольшие численные различия между запусками из-за особенностей вычислений на GPU.
